## ユーザーの目的と決定事項

- スマホ / PC で個人利用する AI Map。ログイン不要を維持する。
- 会話から AI が検索語・条件を決め、候補を個別評価して色付き表示する。「このカフェ、電源ある？」のような選択店舗への追加質問も可能にしたい。
- 個別評価は低コスト・高速な小型モデル。会話用エージェントに検索・比較・調査などのツールを渡す構成を検討する。
- 欲しい機能: 営業中検索、駅＋ブランド検索、徒歩時間比較、ルート検索、経路途中の店、コピー用紙等の商品取扱の調査、電車の移動中に途中下車できる駅の提案。必要な場合に Web 検索を使う。
- 画面外にはみ出す地図上の吹き出しを改善する。チャット・一覧・店舗詳細を、PC のサイドパネル / スマホの高さ可変の下部パネルに集約する案。
- 通常利用の費用目標は **約 $0.20 / セッション、月 5 回で約 $1**。1 セッションは 10〜20 往復・約 10 tool use。初期の $1 / セッション・$5 / 月という案は撤回済み。
- 別枠の外部サービスの上限として、**OpenAI 組織全体の API 利用を月 $10 で強制制限**することを依頼され、設定済み。通常利用目標を月 $10 に増やしたわけではない。
- **Cloud Run の予算による自動停止は不要**という判断で確定。最大 1・最小 0・request-based と既存予算通知で運用する。再度自動停止を提案・導入する必要はない。
- 調査・実装にサブエージェントを使うこと、必要な変更の commit / push はこのセッションで依頼済み。調査の照会メール等は送っていない。

## 設計として選んだ方向と未確定部分

第一候補は Vercel AI SDK の `ToolLoopAgent` + AI SDK UI。Next.js / MUI / Cloud Run を維持し、会話エージェント 1 つに型付きツールを渡す。個別評価はツールなしの小型モデルによる構造化出力として分離する。会話も Luna を基本とし、難しい依頼だけ Terra を検証する。**AI SDK はまだ依存に追加しておらず、バージョン・provider 対応・最小動作は未検証。**

調査上の最大の未解決事項は、Google のデータを外部 LLM へ渡す、独自点数に変換する、保持する範囲の確認。現行アプリが口コミを採点している事実と、その方式を次の設計でも許諾確認済みとして採用できるかは別。Phase 0 で Places、Maps Grounding Lite、Gemini の Maps grounding を比較する。通常検索や合成データでの UI 作業は並行して進められる。

OpenAI の入出力等の共有は Disabled、API call logging は Enabled per call を確認済み。ZDR 契約は未確認。`store=false` だけで全保持がなくなるとは扱わない。根拠と資料は計画書の §3 にある。

費用例の約 $0.074 / 利用、約 $0.37 / 月は仮定計算であり、チャット実測ではない。30 回の会話モデル呼び出し、累計 20 店評価、Web 検索 2 回、Google の対応 SKU 無料枠内等が前提。API の無料枠、インフラ保管費、税等を含めた保証額ではない。

## 開発・検証の引き継ぎ

現在の構成: Next.js 16.3.4 / React 19.2 / MUI 6 / openai SDK 7、モデル `gpt-5.6-luna`。`reasoning_effort: "none"`、strict JSON schema。チャット API はまだなく、`/api/generate-examples` と `/api/analyze-reviews` のみ。

`.mise.toml` は Node 24.20.0、`package.json` は pnpm 9.7.0 指定。通常は依存導入後に次を実行する。

```sh
pnpm lint
pnpm exec tsc --noEmit
node --test src/lib/place-detail-batch.test.mjs
pnpm build
```

今回の実績:

- 3 件のバッチテスト成功、TypeScript 成功、対象コードの ESLint エラーなし。警告 6 件は既存の effect / 宣言順 / コンポーネント定義に関するもの。
- このマシンでは pnpm の shim / Corepack が使えない場面があり、インストール済み Node 24.6.0 とローカル依存の CLI を直接使った。例: `mise exec node@24.6.0 -- node node_modules/typescript/bin/tsc --noEmit`。恒久的な Node 指定は変更していない。
- ローカルの通常ビルドは Google Fonts のネットワーク制限、その後 Turbopack のポート作成制限で失敗。`mise exec node@24.6.0 -- node node_modules/next/dist/bin/next build --webpack` は成功。設定ファイルや本番ビルド方式は変えていない。
- GitHub Actions / Docker の通常の `pnpm run build` と Cloud Run デプロイは成功。CI にこの新規の単体テストや専用 lint ステップはまだ組み込んでいない。
- **取得制限変更後の実ブラウザ操作と実 Google / OpenAI 呼び出しは未検証。** テスト・コードレビュー・ビルド・クラウド割当の読み戻しを行った。E2E 成功や精度・速度の実測済みとは言わない。

Next.js の実効設定は `next.config.js`（standalone 出力）。同名の `next.config.ts` は使われていない。main への push はドキュメントだけでも `.github/workflows/deploy.yml` を起動する。

ブラウザによる料金確認ではユーザーに OpenAI へログインしてもらった。後にプラグイン更新と見られる接続 / モジュールパスの不整合で自動チャージ画面の追加確認が止まった。次回はその時点の利用可能なブラウザツールとログイン状態を確認し、過去の一時変数やキャッシュ内バージョンパスを再利用しない。
