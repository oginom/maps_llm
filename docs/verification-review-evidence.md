# 根拠の口コミ番号：採点 API の確認

ローカルの `/api/analyze-reviews` から実モデルに架空の口コミだけを渡し、電源の有無を条件に採点した。Google Places は呼んでいない。

| 入力 | 応答（どちらも HTTP 200） |
| --- | --- |
| 1: 窓際の席にコンセントあり、2: ケーキの感想、3: カウンター席に電源あり | `{"value":5,"reviewNumbers":[1,3]}` |
| 1: ケーキの感想のみ | `{"value":null,"reviewNumbers":[]}` |

この確認は、実モデルが指定の構造化出力を受け付け、複数件・該当なしの両方を返せることを示す。実店舗に対する採点精度や、根拠が必要十分に選ばれる割合を測ったものではない。
